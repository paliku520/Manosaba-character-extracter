# 魔女语（fiXmArge Language）翻译手册

> 基于 NGA 帖子《[魔法少女的魔女审判] 连梅露露也能学会的魔女语解读(词汇篇)》整理  
> 整理日期：2026-09-06


## 一、语言概述

### 1.1 名称来源

**fiXmArge** 可拆分为：
- **fix**（英）：混合
- **marge**（法）：边缘

字面含义：“混合边缘语言”——暗示魔女语是混合了多种现实语言的产物。

### 1.2 构词核心原则

> **魔女语词汇几乎都只是含义相近的日语、英语词汇的混合。**

- 主要来源：**日语** + **英语**
- 第三来源：**法语**（少量）
- 构词方式：取同义词的读音片段进行拼接
- 大写字母通常标记词素边界

### 1.3 已知使用场景

- OP1：`LaVI-Bavellabion`
- OP2：`MAdEaR MAdEaR`
- 标题曲：`gDie Divil JIO`

## 三、构词规则总结

### 规则 1：日英读音拼接

> 魔女语 = [英语词首/词中] + [日语词尾/词中]（或反过来）

**示例**：
- `hung gement` = 日语 **ha nn**（判决）+ 英语 judge**ment**
- `Guil-me` = 英语 **guil**ty + 日语 罪（tsu**mi**）
- `Tei-Tance` = 日语 **tei**kou（抵抗）+ 英语 resis**tance**

### 规则 2：大写字母标记词素边界

> 拼写中的大写字母指示了混合点的位置

**示例**：
- `fiXmArge` → **fix** + **marge**（X、A 大写）
- `LaVI` → **La** + **VI**（V、I 大写）
- `KaRause` → **ka ra**（日语）+ **ause**（英语）

### 规则 3：同义词“交集”取义

> 词汇含义是两个来源词含义的交集，而非简单加总

**示例**：
- `KaRause` = 日语“**kara**”（因为）+ 英语“be**cause**”（因为）→ 取“因果”的共同语义
- `S~ond‘` = 日语“**so**shite”（然后）+ 英语“a**nd**”（和）→ 取“连接/递进”的共同功能

### 规则 4：少量法语渗透

> 除日英外，法语是第三来源

**示例**：
- `LaVI` 中的 `La` 可能来自法语阴性定冠词
- `FineNd` 中的 `Fin` 来自法语“结束”


## 四、语法推测

> **注意**：以下为基于现有词汇的推测，并非官方设定。

### 4.1 语序

魔女语可能遵循**主谓宾（SVO）**语序，与英语和现代日语（口语）一致。

- `WAirTell`（我） + `Loadeh`（加载） + `Coa Tain`（游戏目录）
- 直译：我加载游戏目录

### 4.2 助词

- `oF` 表所属：`MEif oF JIO` = 角色的图像
- `N'o` 表修饰：功能类似于日语“の”

### 4.3 否定

- 使用 `Nii` 前置或 `-nay` 后缀
- `Ca-nay` = 不能（can + not）
- `UnneYO` = 不需要（un- + necessary）

### 4.4 疑问

- 句末使用 `?` 标示疑问句
- `Alte download Ge-mon?` = 前往下载页面？
