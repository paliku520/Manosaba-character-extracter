# 背景与小素材提取

[![English](https://img.shields.io/badge/English-blue)](backgrounds.en.md)
[![中文(简体)](https://img.shields.io/badge/中文(简体)-red)](backgrounds.md)

在「素材提取」页选择游戏根目录、`backgrounds` 目录或其分类目录。程序自动定位背景和相邻的通用素材包，不依赖角色目录设置。支持从该页拖入游戏目录。

## 使用

1. 点击「加载素材目录」。默认显示场景背景，分类下拉可切换到 CG、证物、人物资料、界面素材和演出图片等。
2. 按素材名称、资源相对路径或来源包名称搜索。勾选用于导出；「全选当前列表」只选当前可见项，跨分类保留勾选；「取消全选」清除所有选择。
3. 点击素材行预览，或聚焦后按 Enter/空格。点击勾选框只改变选择。原有背景包预览首张可用图片，小素材逐张预览。
4. 「加载素材目录」右侧的「预热全部」为所有已加载项缓存缩略图，不受分类或搜索影响，不改变勾选。可取消，再次预热会复用已完成缓存。
5. 点击「导出所选」。原有背景包导出包内全部图片，小素材只导出选中图片。导出可取消，已完成 PNG 保留，失败项单独列出。

预览最长边为 1280 像素，界面显示原始尺寸。导出始终为原始尺寸 PNG，保留透明通道，与角色画质设置独立。素材可能包含剧透。

## 分类与输出

所有输出跟随设置中的输出目录。每个分类文件夹内直接放 PNG，不创建素材包子文件夹。例如：

```text
output/backgrounds/背景/Background_001_001.png
output/backgrounds/证物/Clue_001_013.png
output/backgrounds/人物资料/Profile_Alisa.png
output/backgrounds/界面素材/InputIndicator.png
output/backgrounds/演出物件/1-2-3_Smartphone.png
```

| 分类文件夹 | 来源和分类规则 |
| --- | --- |
| 背景 | 原有 `backgrounds` 下的场景背景、CG 和演出资源包 |
| 证物、人物资料 | `general-witchbook` 的 `Clue_*` 和 `Profile_*` |
| 界面素材 | `general-sprites`、`naninovel-ui`、`resources.assets`、`sharedassets*.assets` |
| 演出物件 | `naninovel-spawn` 中武器、手机、钥匙、纸张、窗帘等命名的图片 |
| 演出人物 | 演出包中以角色命名的图片和部件 |
| 演出背景 | 演出包中的 Background、Frontground、Space 等图片 |
| 演出特效 | CutIn、玻璃碎片、光效、火焰、血迹等图片 |
| 地图素材 | Map、Pin 命名的地图和标记 |
| 演出其他 | kari 等占位图片及无法按名称识别的其他演出图片 |
| 特效纹理 | `general-prefabs` 中的材质纹理 |
| 转场遮罩 | `general-transitions` 中的遮罩纹理 |

演出包包含的所有有效 Sprite 和独立 Texture2D 均收录；分类依据来源和原始名称，无法识别的图片进入「演出其他」。小素材不以像素大小筛选，因此也包含大幅 UI 插图和演出背景。图集 Sprite 逐个列出，引用的底层纹理和 alpha 纹理不再重复列出；保留同包中未被引用的独立纹理。0×0 等没有像素的运行时纹理不属于可导出图片。Unity 内置资源、字体文件、音频和脚本不在此页的范围内。

同名文件自动增加 `_1`、`_2` 等后缀，已有图片不被覆盖。Windows 非法字符和设备保留名会转换为安全名称。输出分类文件夹名称固定为中文，与界面语言独立。

## 预览和缓存

背景扫描只枚举路径；小素材扫描读取 Unity 对象的名称、尺寸和图集引用，不解码像素。小素材扫描在可取消的独立进程中执行，单个来源失败会记录错误，继续扫描其他来源。

预览直接在内存解码、缩小并编码 PNG。扫描完成预先启动专用进程，后续复用。小素材预览复用一个已解析的来源包，切换来源或源文件变化时释放旧包；UnityPy 解码后的图集缓存保留上限为 128 MiB，单次原图解码本身仍有临时内存开销。批量导出同一来源的选中图片只加载一次资源包。

主进程的预览编码数据采用 64 MiB LRU 上限。缩略 PNG 和原始尺寸等元数据保存在 `temp/background-previews/`，重启仍可复用。缓存区分源文件路径、时间、大小、对象类型/ID 和预览尺寸；同包不同图片不会串图。源文件变化或缓存损坏时重新生成，写入通过临时文件和原子替换完成。

全局清理缓存会删除全部素材缩略图，即使选择保留角色预览也会删除这些缓存。退出仅释放预览进程和内存。取消或超时终止所属 worker 进程树，下次请求可重新启动。

## 任务和实现

扫描、预览、预热和导出使用现有提取锁，提供独立 `background_progress` / `background_complete` 事件。进行素材任务时阻止角色任务及缓存清理，避免共用状态栏冲突。界面复用原版标签页、下拉、按钮、列表、弹窗和进度动画，「禁用界面动画」设置继续生效。

PNG 编码完成后才发布最终文件，父进程负责取消后的暂存清理。导出成功按一次任务增加累计次数，全失败或取消不增加。批量导出不自动重试，避免部分完成后产生重复图片；沿用 worker 的 45 秒无进度、600 秒总超时。单个预览请求超时为 45 秒。

| 文件 | 职责 |
| --- | --- |
| `src/background_assets.py` | 背景定位、缩略图、对象缓存键、PNG 保存和按来源批量导出 |
| `src/small_assets.py` | 小素材来源定位、元数据扫描、图集去重、分类和复用来源预览 |
| `src/worker_client.py`、`backend.py` | 可取消扫描/导出和可复用预览进程 |
| `run.py` | 加载、预览、预热、导出 API 与输出分类 |
| `webui/js/backgrounds.js`、`webui/css/backgrounds.css` | 分类、搜索、勾选、预览和原版交互样式 |

## 验证

无需游戏资源的回归检查：

```powershell
python -m unittest discover -s tests -v
```

覆盖目录入口、分类、图集与 alpha 去重、独立纹理、空运行时纹理、64 位对象 ID 字符串、同包不同图片缓存隔离、来源复用与失效、图集缓存上限、单项和跨分类原尺寸 PNG、同名编号、取消/部分失败、缓存复用/清理和进程恢复。

使用自己的游戏资源时检查证物（如 `Clue_001_013` 苹果）、人物资料、图集 Sprite 和演出图片分别预览/导出；检查原始尺寸和透明度、勾选独立性、跨分类选择、预热取消、缓存清理和动画设置。游戏资源与本机提取结果不提交到仓库。
